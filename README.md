# 探究お酒 v1.0

一杯の記録から、お酒の世界へ。個人用の静的PWAです。

## 使い方
ノートから一杯を記録します。銘柄と種類は空欄でも構いません。度数・容量を入れると純アルコール量を計算します。自主目標を超えても実際の記録を保存できます。

日14g・週28g・週2日を初期目標とし、設定で変更できます。これは医学的に安全な量を示しません。週は日本時間の月曜開始、1カード14g、繰越なしです。

最初の感想は原文を保持し、編集履歴と後日の追記を分けます。感想の追記では飲酒量を加算しません。商品と一杯の度数・容量は独立して保存します。

## 保存
IndexedDB `tankyu-alcohol` に端末内保存。ログイン・サーバー送信・自動同期はありません。設定でJSONの完全バックアップ／全置換復元ができます。ダウンロード開始後は、端末にファイルが保存されたことを確認してください。ブラウザのデータ消去で記録は失われます。

## 開発
Node.jsで `npm test`、`npm start`。依存パッケージなし。app/ をGitHub Pagesへ配信します。アプリを更新したら `node tools/build-sw.mjs` を実行してください。

Phase 1は記録・集計・履歴・編集削除・検索・JSON・オフライン対応。事典は分類と計算方法のみ、気になるは案内のみです。詳細商品情報、お気に入り、記事編集、候補登録、比較、CSVはPhase 2対象です。

コーヒーアプリのCSSを参考にしています。coffeeのDB・キャッシュへアクセスしません。公開配信物に個人記録を含めないでください。
